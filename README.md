## Recently shipped

**[dnskit](https://github.com/gladkhumalo/dnskit)** is a command-line DNS troubleshooting toolkit that explains what it finds. It diagnoses resolver failures, DNS hijacking, VPN interference and SPF/DKIM/DMARC email issues, with CI on Windows, macOS and Linux.
